# Этап 0.2: МКБ, УКД, справочник ЭРДБ

Проверено 27.09.2026. Python 3.13.9; Streamlit 1.64.0; pdfplumber 0.11.10; openpyxl 3.1.5. Внешние API и LLM при обработке файлов не вызываются.

## Реализованные контракты

`parse` по умолчанию дополняет записи МКБ/УКД. `--no-enrich` оставляет базовый разбор. Схема обогащённого результата — 1.1. Повторную обработку старого `result.json` выполняет `enrich`, сохраняя новый запуск и проверяя SHA-256 соседнего `source.pdf`.

Каждая запись содержит:

- `icd`: исходная строка, версия каталога, коды, исключения, примеры включения, токены с позициями, журнал исправлений, замечания и статус.
- `field_source_refs`: страницы, таблицы, строки, номера колонок и исходные ячейки. Наследованные условия ссылаются на ячейку родительской строки.
- `ukd.fields`: весь текст проверенных полей, найденные признаки, цитаты/позиции, дерево отношений и неразобранный остаток.
- `ukd.mentions`: плоский список упоминаний. `concept_id` группирует одинаковый признак в контексте диагноза; `mention_id` отличает конкретное место в документе. Эти ID не заменяют ID УКД из ЭРДБ.
- `frequency_branches`: цитата периодичности и цитата условия, связанные с упоминаниями УКД. Например, для J45 сохраняются разные интервалы осмотра при лёгкой, средней и тяжёлой степени.

Условные выражения сохраняют альтернативы, явные конъюнкции и отрицания. Неоднозначные отношения остаются `unresolved`; сочетания типа A/B и степеней тяжести не превращаются в выдуманные комбинации. При замечании базового парсера строка остаётся в очереди проверки независимо от успешного распознавания отдельного признака.

`ErdbRepository` предоставляет `paths_for_icd`, `search_points`, `has_link` и индексы. Каждый путь включает ID обеих связей и ссылки на четыре строки Excel: код→группа, группа, группа→УКД, УКД. Наследование МКБ не применяется к справочнику автоматически. Дубликаты ID исключаются из соединений, исходные строки остаются в снимке. Дубликаты названий не объединяются.

## Проверки

48 автоматических тестов проходят. Они охватывают базовый PDF-парсер, наследование, МКБ, УКД, загрузчик Excel, CLI, сохранение исходных файлов и Streamlit: загрузку, просмотр прямых связей, отсутствие связи с дочерним кодом и сброс результата после смены файла.

Формат описан на https://icdcdn.who.int/icd10/metainfo.html . SHA-256 архива: `a9fa787fa79076e199e46ca645bbc076449853e93e62cd3b2050b96dc96bbc1d`.

Для повторной сборки из этого архива:

```powershell

```

Источник встроен локально; приложение не скачивает классификатор во время анализа. Национальная редакция отдельно не подтверждена. Метаданные ВОЗ используются для структурной проверки, не как полное руководство клинического кодирования.

## Границы текущего этапа

Поддерживаются диапазоны одного уровня с известными концами. Диапазоны разных уровней (`D45–D47.9`, `M33–M33.9`) сохраняются с замечанием. Неизвестные коды не подменяются похожими. При ошибках выражения функции покрытия возвращают неопределённость. Область исключения в скобках заканчивается закрывающей скобкой: в `E22 (исключая E22.8), D35.2` код D35.2 остаётся основным.

Не выполнены: семантическое сопоставление извлечённых УКД с ID ЭРДБ, сравнение приказов 149/75, поиск новых УКД, выводы об обеспечении лекарствами и итоговый отчёт по ТЗ. Для этих следующих этапов готовы структурированные данные и ссылки на источники.

В браузере выполнен полный повторный разбор исходного PDF приказа 75: 37 страниц, 33 таблицы, 536 записей, 411 упоминаний УКД. Открыта новая вкладка «МКБ и УКД», проверено отображение I21/I22 и функциональных классов III/IV с цитатами. Результат сохранён отдельным запуском.
В том же браузере загружен исходный UKD-actualnyi.xlsx: отображаются 71 группа, 149 УКД, 2 657 кодов, 136 замечаний; доступна таблица прямых связей J45, поиск и скачивание JSON. Справочник сохранён в отдельном каталоге data/erdb-96185164c2ab-544beiv2.

## Загрузка нескольких PDF

Добавлен выбор нескольких файлов за один раз и отдельный профиль для каждого. Ошибка одного PDF показывается с его именем и не прерывает обработку остальных. Готовые результаты переключаются через «Результат документа» без повторного разбора; страницы, таблицы и скачиваемые файлы относятся к выбранному источнику. Excel ЭРДБ загружается независимо. Сравнение приказов этим изменением не добавлено.

После изменения пройдены 4 теста интерфейса, включая два различных PDF и повреждённый файл в одном наборе, переключение результата после выбора второй страницы и сброс при изменении набора.
